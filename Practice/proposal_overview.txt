분석 개요

1. 분석 채널

1) 블로그
- 상품과 관련된 개인의 체험기가 위주이며, 텍스트 속에서 긍/부정이 극명하게 드러남
- 협찬 가능성을 배제할 수 없음(글 최하단에 협찬을 명시하는데, 텍스트 형태일 경우 판별 가능하나, 이미지일 경우 협찬 판별 어려움)
- X, 인스타그램, 유튜브 등 SNS의 크롤링이 제한되는 상황에서 대안이 될 수 있음
=> 네이버 API의 경우 최근 1,000개의 데이터만 제공하므로 장기간에 걸친 트렌드 변화를 확인하기는 어려움
ㄴ 주기적으로 API를 활용하여 데이터를 축적하는 방법을 활용한다면 한 달 이상의 데이터로 데이터의 대표성을 축적할 수 있음
ㄴ 수동 크롤링도 고려해봤으나, 네이버의 크롤링 기준에 부적합 (?) 

2) 커뮤니티
- 특정 주제에 특화된 소비자 의견을 파악할 수 있음
ㄴ 디시인사이드, 더쿠, 아카라이브 등의 활성도가 높은 커뮤니티들은 특정 주제를 다루는 별도의 공간이 존재함
- 블로그에 비해 정제되지 않은 인터넷 언어를 사용함
- 동적 구조를 가진 커뮤니티가 적어서, 크롤링이 비교적 용이함

3) SNS(인스타그램, X)
- 가장 빠른 속도로 소비자의 의견이 오가는 채널
- 현재 플랫폼사의 가격 정책으로 인해 대규모 크롤링이 제한됨
- 세부적인 분석 주제와 항목이 정해진 이후 제한된 형태로 데이터 사용 예정


2. 분석 방법

1) 분석 주제 선정 방식
- 대주제는 특정 계층(20대, 청년, 노인, 신혼부부 등)의 라이프스타일과 관련된 소비재 분석
- 산업군, 상품 등의 주제는 초보적인 소셜 리스닝을 통해 확정
ㄴ 상품군을 선정하는 이유를 더욱 명확하게 해야 함 ->  점수표를 만들거나 비교적 객관적인 체계를 만들어 줘야 함(향후 과제)
- 분석 상품군이 정해진다면, 시장 조사를 통해 해당 상품군이 마주하고 있는 문제들을 탐색 (문헌조사 등의 방식으로)

2) 분석 방법론

(1) 소셜데이터의 정형화
- 현재 접근 가능한 정형데이터가 없기에 소셜 데이터를 최대한으로 활용
- 주제 선정 및 대략적인 트렌드 파악 과정에서 소셜데이터를 활용 -> 빈도기반 분석
- 주제 선정 이후, 상품군에 대한 심화 분석 시에는 소셜데이터를 정형화하고, 파생변수를 생성하여 ML/DL 등의 방법론 사용

(2) +a
- 분석을 진행하면서 적합하다고 판단되는 방법론을 추가 예정
